Workflows

Each workflow is a multi-agent program running against mockagents. Every model call goes over the real OpenAI, Anthropic or Gemini wire format, costs nothing, and behaves the same way every time. Pick an example, edit the input, and launch.

Select a run, or launch one from the Workflows tab.

Human review

Blocking checkpoints (output_gate, tool_approval) hold a run in awaiting_review or awaiting_approval until you decide, or until the review timeout fires. Every AI output is also logged as a non-blocking output_audit item that you can approve or flag.

Messages go through POST /api/agents/{name}/invoke. Try hello, what workflows exist? or how do retries work? with the assistant. Pick drill-flaky, drill-streamcut or drill-ratelimited to watch retries, stream recovery and fallback happen live.

Interaction log

mockagents records every request it serves. This view is the mock's side of the conversation: the matched scenario, token counts and cost.

Native pipeline

pg-native-brief runs inside mockagents (planner → researcher → SLM summarizer). It is a contract simulation with no tools, retries or reviews. Compare it with the playground's research-brief orchestrator.

Fixture editor

Edit a mock fixture live through the mockagents write API (PUT /api/v1/agents/{name}). The registry swaps it in atomically and validates it first. Reload restores the file on disk and re-arms fail_first chaos counters.
