# Getting help

| You want to… | Go to |
| --- | --- |
| Ask a question, share an idea, show what you built | [GitHub Discussions](https://github.com/mockagents/mockagents/discussions) |
| Report a bug | [Open an issue](https://github.com/mockagents/mockagents/issues/new/choose) with the output of `mockagents --version`, the agent YAML and the request that misbehaved |
| Report a security vulnerability | **Privately**, as described in [SECURITY.md](SECURITY.md) — never in a public issue |
| Read the documentation | [The user guide](site/docs/) and [ARCHITECTURE.md](ARCHITECTURE.md) |

## Supported versions

See [SECURITY.md](SECURITY.md#supported-versions). Bug fixes land on `main` and
ship in the next release.

## Response times

Issues and pull requests get a first response within a week; see
[CONTRIBUTING.md](CONTRIBUTING.md#what-we-owe-you-back). MockAgents is maintained
by volunteers and has no paid support.
