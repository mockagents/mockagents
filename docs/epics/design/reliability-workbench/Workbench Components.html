Status badge

Dot + text, never color-only. States: ok / warn / bad / info / neutral / outline (unknown). “Unknown” uses the outline variant with explicit text — never rendered as zero or empty.

Code editor & diff view

Line-numbered textarea (error lines flagged in the gutter + inline message); diff renders del/add with +/− text markers so color is not the only signal. Both bounded and lazy — bodies over 64 KB show the truncation notice instead of rendering.

Confirmation dialog (destructive)

Impact summary → irreversible consequences → exact-name entry gates the destructive button. Focus trapped; Esc cancels; destructive button is the only .danger element on screen. Never auto-focused on the destructive action.

Receipt line / save receipt

Post-apply state card: new revision, runtime state, file state, audit ref. Two variants: persisted (ok) and runtime-only (warn). Appears only after server confirmation — no optimistic "saved" toast exists in this system.

Keyboard & focus order
