# Mounted HTTP route catalog

Generated from adapter route literals and main/MCP/A2A mounting calls, including Chroma's composed path. This is the built-in route superset; [API documentation](../api.md) explains conditional mounts, bodies, errors, auth, and RPC methods. Management floors apply only in multi-tenant mode; `roleOpen` means any authenticated role except explicitly public probes. Provider routes allow anonymous access and optionally resolve valid MockAgents credentials. Standalone MCP/A2A listeners do not inherit the main server's middleware. `GET` ServeMux patterns also accept `HEAD`.
