# MockAgents v0.5.0 — the production-readiness release

**Mock the OpenAI, Anthropic & Gemini APIs — and MCP & A2A agents — with zero LLM calls.**

v0.4.0 was the first public release and it worked, as long as you ran it the way
it was demonstrated: one process, on a laptop, trusted network. This release is
what happened when we audited it as if someone were about to run it as shared
infrastructure.

The [production-readiness audit](../reviews/2026-09-03-production-readiness-audit.md)
found 96 verified issues and scored the project 5.2/10 for that use. Fifteen fix
iterations answered the critical, high and medium tiers. Almost nothing here is
a new feature; it is the difference between "it demos" and "you can run it".

---

## Read this first

Several defaults changed because the old ones were unsafe. If you are upgrading,
these are the ones that can change behaviour for existing callers.

| Change | What to do |
|---|---|
| `POST /v1/engines/process` is no longer mounted | Pass `--engine-endpoint` if a harness depends on it |
| Pipeline writes need the **platform** role in multi-tenant mode | Use a platform key for `PUT /api/v1/pipelines/{name}` |
| Multi-tenant CORS is no longer `*` | Set `--cors-origins` for browser clients other than the loopback GUI |
| `record` / `replay` bind to `127.0.0.1` | Pass `--bind 0.0.0.0` if you reached them over the network |
| `DELETE /api/v1/logs` needs **admin** | Use an admin key |
| The bootstrap platform key is no longer printed to stderr | Read it from the key file, or supply it with `MOCKAGENTS_BOOTSTRAP_KEY` |
| A chart deployment is single-replica unless acknowledged | Set `multiReplica.acknowledged=true`, or point replicas at shared Postgres |

## What got fixed

### Multi-tenant mode is now actually isolated

The audit's central finding was that tenancy had been retrofitted onto
name-keyed structures, and several of them still keyed on the name alone. The
file watcher reloaded across tenant boundaries, the platform role read every
tenant's data implicitly, and chaos fail-first counters and rate-limit windows
were shared — so one tenant's traffic produced `429`s for another. All of those
are scoped per tenant now.

Authentication got a per-IP failure limiter and a negative cache, so a
credential-stuffing loop no longer costs a bcrypt hash per attempt, and client
IPs come from a trusted-proxy allowlist instead of an unvalidated header.

### Recording no longer loses data

`Cassette.Append` rewrote the whole file outside its mutex: two concurrent
recorders raced on the rename and one silently overwrote the other's
interactions. Appends are single-writer and one line at a time now. A non-JSON
response body — an HTML error page from a gateway — no longer fails the write
either, and a recorded SSE stream is no longer cut off at 60 seconds by a
whole-request timeout.

### Operational surfaces that were missing

Tracing was dead code: the provider was never constructed, so the documented
`OTEL_EXPORTER_OTLP_ENDPOINT` produced no spans and no error to explain why. It
is wired now, and an incoming `traceparent` is joined so the mock appears inside
the caller's trace.

Graceful shutdown drains in-flight work with a readiness signal instead of
cutting it. There is a new [operations guide](../../site/docs/guides/operations.md)
covering backup and restore, platform-key recovery, secret rotation, the move to
Postgres, upgrades and replica limits, and a
[configuration reference](../../site/docs/reference/configuration.md) listing
every environment variable — with a test that fails when a new one ships
undocumented.

### Faster where it was measurably slow

The session store took an exclusive lock on every request, including the hit
path that mutates nothing; hits take a read lock now. Vector queries cloned
every candidate's metadata before ranking truncated the result, so a
10,000-point collection allocated 10,000 maps to return three; the clone happens
after truncation.

### SDK and GUI

The TypeScript SDK now accepts CRLF-terminated SSE frames, and its timeout
bounds the wait for response headers rather than the whole stream, so a long
stream is no longer aborted mid-flight. The Go SDK's tool-call assertions read
the whole trajectory, which is what the Python and TypeScript SDKs already did
and what `tool_call_sequence` means in a `kind: TestSuite` document.

The web console moved to a Next.js release without the four server-action
advisories, its login redirect guard parses the URL instead of pattern-matching
it, and every management-API call now carries a timeout.

## Install

Binaries are attached to this release for macOS, Linux and Windows. Asset names
carry the version, for example `mockagents_0.5.0_linux_amd64.tar.gz`.

```bash
go install github.com/mockagents/mockagents/cmd/mockagents@v0.5.0
```

The npm, PyPI, Docker Hub and Homebrew paths still depend on account setup that
has not been completed — see [RELEASING.md](../RELEASING.md). Until then, use
`go install` or a prebuilt binary.
