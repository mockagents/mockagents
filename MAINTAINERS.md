# Maintainers

Maintainers review and merge pull requests, triage issues, cut releases and
handle security reports. How someone becomes (or stops being) a maintainer is
described in [GOVERNANCE.md](GOVERNANCE.md); the paths each area covers are in
[.github/CODEOWNERS](.github/CODEOWNERS).

## Looking for maintainers

The project has a bus factor of one. Regular contributors who want to take on
review responsibility for an area — the SDKs, the GUI, protocol adapters,
documentation — are very welcome; see [GOVERNANCE.md](GOVERNANCE.md#becoming-a-maintainer).

## Triage

Issues and pull requests get a first response within a week (the promise in
[CONTRIBUTING.md](CONTRIBUTING.md#what-we-owe-you-back)). Until there is a second
maintainer, triage is done by the maintainer above.
